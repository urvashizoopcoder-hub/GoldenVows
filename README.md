# GoldenVows — Celebration Studio & 60 Unique Luxury Invitation Templates

An artisanal digital invitation platform and customization studio for **Weddings**, **Engagements**, **Baby Showers**, **Birthdays**, **Housewarmings**, and **Anniversaries**.

Features **60 standalone, unique templates** with individual URLs, mobile and laptop responsive layouts, interactive 3D Page-Turning Flipbook mode, Royal Scroll mode, Incoming VIP Call & Wax Seal Envelope openers, live countdown timers, interactive Google Maps, and direct WhatsApp and Email delivery to the exact recipient number.

## ✨ Key Capabilities

1. **First Page Customization Studio (`index.html`)**:
   - Multi-occasion selector: Wedding, Engagement, Baby Shower, Birthday, Housewarming, Anniversary.
   - Dynamic form fields & celebration presets.
   - Multi-device live preview frame: Phone (390px), Tablet (620px), and Laptop views.
   - Live real-time preview updates as you type.

2. **Dual Experience Modes**:
   - **📖 3D Page-Turning Flipbook Mode**: Realistic page-turn album with smooth transitions, page curl, tactile navigation, and page indicators.
   - **📜 Royal Scroll Mode**: Seamless animated vertical palace journey with parallax and reveals.

3. **Incoming VIP Call & Wax-Sealed 3D Envelope**:
   - Incoming call screen with caller portrait, pulsing glow, slide-to-answer bar, and personalized greeting ("Incoming call for [Guest Name]").
   - Royal wax-sealed envelope with authentic unsealing interaction.

4. **Guaranteed WhatsApp & Email Delivery**:
   - Country code selector (+91, +1, +44, +971, +61, +65, etc.).
   - Automatic phone number sanitizer (cleans spaces, dashes, parentheses, leading zeros) ensuring delivery directly to the correct WhatsApp number.
   - Personalized message generator and 1-click email dispatching.
